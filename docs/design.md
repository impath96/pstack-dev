# 할 일 앱 설계 결정

레이아웃은 프로토타입 비교가 정했고, 구조는 arena 두 후보의 합성으로 정했습니다.
이 문서는 왜 지금 모양인지를 남깁니다. 코드가 보여주는 것은 반복하지 않습니다.

## 확정 사항

바닐라 JS, 빌드 단계 없음, 정적 서버로 서빙합니다. 저장은 localStorage입니다.
레이아웃은 상태별로 묶은 조밀한 목록 하나입니다. 범위는 CRUD와 상태 전이입니다.

## 베이스와 이식

후보 둘을 각각 다른 모델로 병렬 설계했고, 읽기 전용 교차 판정자가 6개 기준으로 채점했습니다.
저와 판정자가 독립적으로 같은 베이스를 골랐습니다.

베이스는 후보 1입니다. 결정적 근거는 두 가지입니다.

`project(state, today)` 투영 계층이 도메인 판단을 전부 해소해서 `views.js`에 도메인 조건문도
한글도 남지 않습니다. 렌더러가 "이게 어느 그룹인지, 마감이 지났는지, 버튼이 비활성인지"를
묻지 않습니다.

리듀서의 동일성 불변식입니다. 바뀐 게 없으면 리듀서가 입력과 같은 객체를 돌려주고,
`next.todos === state.todos`가 정확히 "할 일이 하나도 안 바뀜"을 뜻합니다. 셸은 이 동일성
비교만으로 저장과 재렌더를 건너뜁니다. 모든 명령이 공짜로 멱등해집니다. diff 코드가 없습니다.

후보 2에서 네 가지를 이식했습니다.

**상태 테이블 하나로 통합.** 후보 1은 `STATUS_ORDER`, `STATUS`, `TRANSITIONS`에 `STATUS_LABEL`까지
같은 키를 네 군데에 들고 있었습니다. 상태 하나 추가에 두 파일 네 곳을 고쳐야 하고 어긋나도
아무도 모릅니다. 후보 2처럼 `STATUSES` 한 테이블로 합치고 순서는 키 순서에서, 타입은 테이블에서
파생시킵니다. 파생할 수 없는 라벨 목록은 임포트 시점에 키 일치를 단언해서 어긋나면 첫 로드에서
터집니다.

**신버전 데이터를 덮지 않습니다.** 후보 1은 모르는 버전을 손상으로 보고 격리 후 시드로 돌아갑니다.
후보 2는 디스크를 그대로 두고 메모리 전용으로 떨어집니다. 구버전 빌드가 신버전 데이터를 치우는
일이 없어야 하므로 후보 2를 택했습니다. 진짜 깨진 JSON에 대한 격리는 후보 1 그대로 둡니다.

**삭제 확인 대화상자를 되돌리기로 교체.** 후보 1은 `window.confirm`을 씁니다. 확인창은 모든 삭제에
비용을 물리고 자동화를 막습니다. 되돌리기는 의도한 삭제에 비용이 0입니다.

**마감일을 선택 항목으로.** 후보 1은 마감일을 필수로 모델링했습니다. 마감 없는 할 일이 정상이므로
`IsoDate | null`로 바꿨습니다.

## 베이스에 직접 가한 수정

`project()`를 `view-model.js`로 분리했습니다. 후보 1은 `domain.js`가 `strings.js`를 임포트해서
도메인 테이블이 한글 라벨을 들고 있었습니다. 판정자가 도메인 모듈에 표현 정책이 섞였다고
지적했고 맞는 지적입니다. 이제 `domain.js`는 아무것도 임포트하지 않습니다. 투영이 도메인과
문자열을 둘 다 아는 유일한 지점입니다.

## 거절한 것

후보 2의 폴더 구조를 거절했습니다. 같은 앱에 16파일 6폴더는 클릭에서 저장까지 추적하는 데
네 파일 이상을 읽게 만듭니다. 베이스는 세 파일입니다.

후보 2의 `TodoDraft`에서 `status`를 빼는 방식을 거절했습니다. 구조적으로는 더 안전하지만
칸반이 없는 지금 뒤로 가는 이동에 별도 버튼이 필요해집니다. 에디터의 상태 `<select>`를
`allowedTargets()`로 만들면 불법 이동이 UI에 표현되지 않으면서 양방향이 한 컨트롤로 끝납니다.

레코드별 localStorage 키를 거절했습니다. 탭 간 충돌 창을 없애지만 키 인덱스와 병합이 필요하고
마이그레이션이 원자적이지 않게 됩니다. 단일 사용자 로컬 목록에는 엔벨로프가 맞습니다.

## 받아들인 트레이드오프

변경마다 목록 전체를 다시 그립니다. diff 코드가 없는 대가입니다. 수백 행까지 쌉니다.
에디터 다이얼로그는 이 재렌더에서 제외되고, 같은 할 일에 새 오류가 없으면 입력을 건드리지
않습니다. 다른 탭의 쓰기가 타이핑 중인 제목을 지우지 않게 하는 유일한 조정 지점입니다.

탭 간에는 마지막 쓰기가 이깁니다. `storage` 이벤트로 수렴하지만 같은 이벤트 루프 턴에 두 탭이
쓰면 하나가 사라지는 창이 남습니다.

## 검증 스킬에 생기는 부채

영속성이 "리로드가 곧 리셋"을 깨뜨립니다. 기능 맵 네 파일 중 셋이 사라진 레이아웃을 설명합니다.
`launch.sh`와 `doctor.sh`는 포트 소유권을 프로토타입 제목 문자열로 확인하므로 실제 앱에
그대로 쓰면 실패합니다. 직접 읽고 확인한 사실입니다. 구현 후 한 번에 정리합니다.
